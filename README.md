# 🐧 RebuiltFedora

**A lightweight Fedora-based desktop operating system built around XFCE.**

RebuiltFedora is a personal Linux distribution project focused on keeping Fedora familiar while providing a lightweight, clean, and customizable desktop experience.

## ✨ Goals

- 🪶 Lightweight **XFCE** desktop
- 🐧 Fedora-based system
- 📦 Native Fedora `dnf` package management
- 💿 Bootable and installable ISO images
- 🎨 Custom RebuiltFedora branding
- ⚡ Sensible defaults without unnecessary bloat
- 🤖 Automated ISO builds with GitHub Actions

## 🖥️ Desktop

RebuiltFedora uses **XFCE** as its primary desktop environment. XFCE keeps the desktop responsive while using fewer resources than heavier desktop environments.

## 📦 Package Management

RebuiltFedora uses Fedora's native package ecosystem and `dnf` for installing and updating software.

```bash
sudo dnf install <package>
sudo dnf update
```
